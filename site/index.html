03 // How it works

One runtime. No web view.

The backend and tray service live in an app-level runtime. Closing to tray destroys the visible window, pauses UI events and keeps effects and macros running; the tray task rebuilds the window on demand.

OpenRazer is the source of truth. Rusted Snake introspects the daemon and builds controls from the interfaces it finds. OpenRGB is a separate, optional stack for everything else.

  1. 01 / HARDWARE

    OpenRazer daemon

    Device discovery, lighting zones, DPI, polling and battery over D-Bus. Every device returned by the daemon is listed.

    Source of truth
  2. 02 / APPLICATION

    Rusted Snake

    Rust backend, raw HID writer, software lighting and macro engine. A single GPUI window paints the whole interface.

    Tray-safe runtime
  3. 03 / FALLBACK

    OpenRGB CLI

    Optional bridge for motherboards, DRAM, speakers and Razer devices OpenRazer misses. Static controls, not live effects.

    External
No cloud. No account. No telemetry. Settings and macros are local JSON. Onboard profiles live in the device.

04 // Device support

Coverage, honestly stated.

Rusted Snake lists every device OpenRazer returns and exposes only the controls the daemon actually supports. Experimental features are labelled as such.

Read the support matrix
Feature Coverage Status
Discovery & telemetry Any device returned by org.razer.getDevices. Model, firmware, serial and battery come from razer.device.misc and razer.device.power. OpenRazer
Lighting & zones chroma, logo, scroll, left, right, backlight and legacy bw2013. Effects appear only when the daemon exposes them. D-Bus
DPI & polling DPI and poll-rate methods. Polling choices are 125, 500, 1000, 2000, 4000 and 8000 Hz. Live
Onboard profiles Raw HID. Naga Trinity (1532:0067) is verified; other Razer mice are probed read-only and need Experimental saving. Verified
Macros Any Razer evdev keyboard or mouse. Trigger list defaults to Naga side buttons plus key capture. Broadly tested with a mouse. Tested
Audio-reactive At least one static-capable zone. Colours are per-zone, not per-key matrix animations. Per-zone
OpenRGB tab Any controller the openrgb command lists, including non-Razer hardware. Lighting modes, zones, colour, brightness and speed only. CLI
Keyboard remapping OpenRazer binding and macro interfaces are not used. Keyboard onboard profiles are not handled in this rewrite. Not included

OpenRazer is the source of truth. Controls are built by introspection, not a hardcoded device list. If the daemon does not expose an interface, Rusted Snake does not invent it.

05 // Install

Install on any Linux distribution.

The installer builds the release binary and adds the app menu entry, icons and optional udev permissions. Prefer to build it yourself? Cargo is one command away.

Linux · Wayland / X11
install.sh — recommended 
# Clone the repository
git clone https://github.com/henrychea/rusted_snake.git ~/rusted_snake
cd ~/rusted_snake

# Build, install to ~/.local, add the desktop entry and icons
./install.sh

# Add raw-HID and uinput rules for onboard profiles and macros
./install.sh --with-udev
cargo — build from source 
# Requires Rust 1.90+ and the GPUI build dependencies
git clone https://github.com/henrychea/rusted_snake.git
cd rusted_snake
cargo build --release -p rusted-snake
./target/release/rusted-snake

# Or let the launcher build, update from git and run
~/rusted_snake/bin/rusted-snake
udev — raw HID and uinput 
# Onboard profiles: allow raw HID access
sudo cp linux/70-rusted-snake-hidraw.rules /etc/udev/rules.d/
sudo cp linux/99-rusted-snake-uinput.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules && sudo udevadm trigger

# Macros: allow evdev reads and uinput injection
sudo usermod -aG input "$USER"

# Sign out and back in after changing groups

Installs to ~/.local/bin/rusted-snake with the desktop ID com.henrychea.RustedSnake. Use ./install.sh --system, --no-build, --uninstall or --prefix=/opt as needed.

Before you start

  • Linux with Wayland or X11 and a Vulkan-capable GPU
  • OpenRazer daemon running and your user in the openrazer group
  • Rust 1.90+ and the GPUI build dependencies
  • PipeWire or PulseAudio for audio-reactive lighting
  • openrgb on PATH for the OpenRGB tab — optional
Build dependencies

Arch base-devel clang pkgconf wayland libxkbcommon vulkan-icd-loader vulkan-headers fontconfig freetype2

Debian / Ubuntu build-essential clang pkg-config libwayland-dev libxkbcommon-dev libvulkan-dev libfontconfig1-dev libfreetype6-dev libx11-dev libxcb1-dev
